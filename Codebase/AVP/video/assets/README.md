# Laptop artwork

`laptop-studio.png` is original decorative mockup artwork created with the built-in image-generation tool for this commercial. It is a photorealistic generated device, not a photograph or third-party branded asset. No source reference footage or audio was incorporated.

Prompt used with the built-in tool (`transparent_background: true`):

> Create ONE photorealistic premium laptop mockup asset for compositing real software footage into a commercial video. Isolated transparent background, no environment, no text or logos. Straight-on centered symmetric front view at screen eye level with a modest view down onto the keyboard deck, laptop open, display plane exactly frontal rectangular with horizontal and vertical edges (no yaw, no roll, no skew). Entire laptop visible with generous transparent margins. Space-gray aluminum thin laptop, physically realistic metal highlights, black keyboard with individual keys clearly visible, large glass trackpad, hinge, subtle port edges, thin black bezel and webcam. Blank uniformly solid black unlit display, aspect ratio16:10, no gradients or reflections over the screen insert region. Real studio product photography / high-end 3D product render quality, tangible thickness, realistic keyboard deck perspective and shadows on the body. Do not draw a flat UI illustration, icon, vector frame, rounded rectangle or abstract monitor. Wide landscape canvas, device fills85%width and85%height. Background genuinely transparent alpha including outside device. The screen will be replaced later with actual software capture; do not generate screen UI.


Canvas: 1536×1024. Display insert: x223, y96, width1090, height630. Preserve asset aspect ratio and alpha. Render preparation copies this directory to `public/devices/`.

## Codi mascot

`codi.svg` is the user-supplied `cody_codineo_mascot_transparent.svg`, copied byte-for-byte. The user names the mascot **Codi**. Its embedded image and design are preserved; only whole-artwork position, scale, opacity and rotation are animated.
